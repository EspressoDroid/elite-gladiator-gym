# Elite Gladiator Gym — website concept

A dependency-free, bilingual single-page website based on Elite Gladiator Gym’s public Instagram positioning.

## Preview

From this directory, run any static server, for example:

```powershell
python -m http.server 4173
```

Then open `http://localhost:4173`.

## What is included

- Macedonian-first content with an English language switch.
- Responsive desktop and mobile layouts.
- Keyboard-accessible navigation and visible focus states.
- Reduced-motion behavior.
- Direct `tel:` and official Instagram application handoffs.
- Six user-supplied facility photos, locally optimized for web delivery and art-directed across the hero, club, fitness, wellness, and interior-gallery sections.
- User-supplied official Elite Gladiator logo, with a transparent background for the cropped header mark and full footer lockup.
- Original SVG/CSS artwork layered with the supplied photography.
- No analytics, cookies, tracking, forms, third-party scripts, or external font dependencies.

## Before production launch

- Replace `noindex, nofollow` after approving the live domain.
- Add the final canonical URL and an absolute Open Graph image URL.
- Confirm the final legal entity name, address, privacy/legal links, opening hours, current price, and current membership availability with the club.
- Replace or approve the original concept mark if the official brand asset may be used.
- Confirm final publication rights and any needed appearance releases for the supplied facility photos.
- Connect a client-owned application endpoint only after its data handling and consent language are approved.
- Verify Safari/iOS on a real device and run performance checks against the deployed URL.
